    PSFMachine Polar B-Spline Builder

    Polar B-spline ePSF modeling for Roman WFI detectors.

    builder

    roman_epsf.psfmachine.builder

    PSFMachine-style polar B-spline ePSF construction using pure NumPy / SciPy.

    Methodology (Hedges et al. 2021)
    1. Extract cutout stamps around a selection of stars.
    2. Normalise each stamp's pixel values by the catalog flux estimate for the corresponding star.
    3. Record the per-pixel offset from the star position in detector pixels (delta_col, delta_row).
    4. Convert to polar coordinates (r, phi) and fit a B-spline model on the polar grid to the assembled normalised-flux vs. position data.
    5. Evaluate the fitted model on any oversampled pixel grid.

    The star-selection step deliberately uses looser criteria than the photutils path (fainter stars are accepted because flux normalisation removes the brightness dependence).

    PSFMachineModel dataclass

    Container for a fitted B-spline ePSF model.

    Supports two coordinate systems controlled by the coords attribute:

    "polar" Tensor product of radial clamped B-splines × periodic azimuthal B-splines, with a radial-only core inside cut_r. Uses r_knots for the radial basis.

    "cartesian" Full 2D tensor product of clamped B-splines along the column and row axes, with sqrt-spaced knots inside cut_r for higher resolution at the PSF core. Uses r_knots for the column axis and row_knots for the row axis.

    The :meth:evaluate method automatically dispatches to the correct design matrix based on coords.

    Attributes:

    Name Type Description
    weights ndarray

    Fitted B-spline coefficients.
    r_knots ndarray

    Radial knot positions for polar mode, or column-axis knot positions for Cartesian mode.
    n_r_knots int

    Number of radial / column knots.
    n_phi_knots int

    Number of azimuthal knots (polar mode). 0 for Cartesian mode.
    rmin float

    Inner radial limit in detector pixels (polar mode).
    rmax float

    Outer radial / domain half-width limit in detector pixels.
    cut_r float

    Polar: radius below which only radial terms are used. Cartesian: transition radius from sqrt-spaced to linear knots.
    degree int

    B-spline degree (default 3 = cubic).
    n_stars int

    n_pixels int

    coords str

    build_pixel_arrays 

    build_pixel_arrays(
    image: ndarray,
    dq: ndarray | None,
    selected_stars: DataFrame,
    cutout_size: int,
    flux_col: str | None = None,
    background: str | None = "local",
    sigma_clip_bg: float = 3.0,
    norm_mode: str = "catalog",
) -> tuple[ndarray, ndarray, ndarray, ndarray]

    Assemble per-pixel offset and normalised-flux arrays from star cutouts.

    For each star in selected_stars a cutout_size × cutout_size stamp is extracted, background subtracted (optionally), normalised by the catalog flux estimate, and flattened. All stars are concatenated into 1D arrays ready for :func:fit_epsf.

    The star-selection can be looser than for the photutils path: fainter and less isolated stars are acceptable because flux normalisation removes the brightness dependence.

    Parameters:

    Name Type Description Default
    image ndarray

    2D background-subtracted science image (detector pixels).

    		 required
    dq ndarray or None

    2D data-quality array. Bits DO_NOT_USE and SATURATED are masked when roman-datamodels is available; otherwise all non-zero DQ values are masked.

    		 required
    selected_stars DataFrame

    Catalog rows with columns x_pix, y_pix, and a flux column (auto-detected from flux_col or common catalog column names).

    		 required
    cutout_size int

    Side length of each star stamp (pixels).

    		 required
    flux_col str or None

    Catalog column containing the flux normalisation value. If None, the first matching column among ['segment_flux', 'psf_flux', 'aper_flux', 'kron_flux', 'flux'] is used.

    		 None
    background ('local', None)

    Per-cutout background mode: * 'local': subtract the median of stamp pixels that fall within sigma_clip_bg × std of the stamp median. This selects sky-like pixels (i.e. those not dominated by source flux) across the whole stamp rather than just the border ring. * None: no per-cutout subtraction (assumes image is already background-free).

    		 'local'
    sigma_clip_bg float

    Number of standard deviations from the stamp median used to define "sky" pixels. Default 3.0 (1-sigma clipping retains only the faint background pixels; increase to be more inclusive).

    		 3.0
    norm_mode ('catalog', 'measured', 'core')

    How each stamp is flux-normalised before fitting: * 'catalog' (default): divide by the flux value in flux_col. * 'measured': divide by the sum of all finite, unmasked stamp pixels after background subtraction. Falls back to catalog flux when the measured sum is ≤ 0 or not finite. * 'core': divide by the sum of finite, unmasked pixels within a 3 px radius of the star centre. This avoids inflating the denominator with extended-wing flux and is more robust for PSFs with diffraction spikes. Falls back to catalog flux when the core sum is ≤ 0 or not finite.

    		 'catalog'

    Returns:

    Name Type Description
    delta_col ndarray

    Column offsets from star centre, shape (n_valid_stars, cutout_size²). Always fully populated (no NaN).
    delta_row ndarray

    Row offsets from star centre, shape (n_valid_stars, cutout_size²). Always fully populated (no NaN).
    norm_flux ndarray

    Normalised pixel fluxes pixel_flux / catalog_flux, shape (n_valid_stars, cutout_size²). Masked or bad pixels are NaN.
    star_idx ndarray

    1D integer array of shape (n_valid_stars,) mapping output row i to the row position of that star in selected_stars.

    evaluate_epsf 

    evaluate_epsf(
    model: PSFMachineModel,
    cutout_size: int | None = None,
    oversampling: int = 4,
    x_0: float = 0.0,
    y_0: float = 0.0,
    clip_negative: bool = False,
    normalise: bool = True,
) -> ndarray

    Evaluate the ePSF model on an oversampled pixel grid.

    The grid is centred at (x_0, y_0) (sub-pixel offset from the nearest detector pixel centre) and spans cutout_size native pixels in each dimension sampled at oversampling times the native pixel spacing. The evaluation covers the entire square pixel grid including all four corners.

    Parameters:

    Name Type Description Default
    model PSFMachineModel

    Fitted B-spline ePSF model.

    		 required
    cutout_size int or None

    Stamp size in native detector pixels. Defaults to model.cutout_size if set on the model, otherwise 25.

    		 None
    oversampling int

    Oversampling factor (number of sub-pixels per native pixel). Default 4.

    		 4
    x_0 float

    Sub-pixel offset of the star centre from the nearest pixel centre (in native pixels). Default (0, 0).

    		 0.0
    y_0 float

    Sub-pixel offset of the star centre from the nearest pixel centre (in native pixels). Default (0, 0).

    		 0.0
    clip_negative bool

    Set negative model values to zero. Default False (unnecessary when model.log_fit=True since 10^x > 0).

    		 False
    normalise bool

    Normalise the image so it sums to 1 on the native pixel grid (or to oversampling² on an oversampled grid before any renormalisation). Default True.

    		 True

    Returns:

    Type Description
    ndarray

    2D oversampled ePSF image of shape (cutout_size * oversampling, cutout_size * oversampling).

    fit_epsf 

    fit_epsf(
    delta_col: ndarray,
    delta_row: ndarray,
    norm_flux: ndarray,
    n_r_knots: int = 18,
    n_phi_knots: int = 15,
    rmin: float = 0.05,
    rmax: float | None = None,
    cut_r: float = 3.0,
    degree: int = 3,
    prior_sigma: float | None = 1000.0,
    norm_flux_err: ndarray | None = None,
    coords: str = "polar",
    n_col_knots: int | None = None,
    n_row_knots: int | None = None,
    log_fit: bool = False,
    cutout_size: int | None = None,
) -> PSFMachineModel

    Fit a B-spline ePSF model to normalised pixel data.

    Two coordinate systems are supported via coords:

    "polar" (default) Fits a tensor-product model in (r, phi) polar coordinates. The radial basis uses clamped cubic B-splines on sqrt-spaced knots. The azimuthal basis uses periodic wrapped cubic B-splines. Inside cut_r only radial terms are active (no azimuthal modulation).

    "cartesian" Fits a full 2D tensor-product model in (delta_col, delta_row). Knots are sqrt-spaced near the PSF core (within cut_r) for both axes, transitioning to linear spacing outside. The design matrix is the outer product of two 1D B-spline bases.

    Inputs can be either 1D (n_pixels,) or 2D (n_stars, n_pixels_per_star) arrays (the output shape of :func:build_pixel_arrays). 2D inputs are ravelled internally before fitting.

    Parameters:

    Name Type Description Default
    delta_col ndarray

    Pixel offsets from star centres. Shape (n_pixels,) or (n_stars, n_pixels_per_star).

    		 required
    delta_row ndarray

    Pixel offsets from star centres. Shape (n_pixels,) or (n_stars, n_pixels_per_star).

    		 required
    norm_flux ndarray

    Normalised pixel fluxes. NaN values (masked pixels) are excluded automatically. Same shape as delta_col.

    		 required
    n_r_knots int

    Polar: number of radial knots (sqrt-spaced in [rmin, rmax]). Cartesian: number of knots per axis when n_col_knots / n_row_knots are not supplied. Default 24 (increased for sharp Roman WFI core).

    		 18
    n_phi_knots int

    Number of azimuthal knots (polar mode only). Ignored for Cartesian. Default 15.

    		 15
    rmin float

    Inner radial limit in detector pixels (polar mode). Default 0.05 (was 0.5 — reduced so the brightest center pixel is always fitted and evaluated rather than zeroed).

    		 0.05
    rmax float or None

    Outer radial limit (polar) or domain half-width (Cartesian) in detector pixels. When None (default), auto-computed to cover the full input pixel grid including all four corners: sqrt(2) * (cutout_size/2 + 0.5) if cutout_size is known or inferred from 2D inputs, otherwise max(hypot(delta_col, delta_row)).

    		 None
    cut_r float

    Polar: radius inside which only radial terms are modelled. Cartesian: transition radius from sqrt-spaced to linear knots. Default 3.0.

    		 3.0
    degree int

    B-spline degree. Default 3 (cubic).

    		 3
    prior_sigma float or None

    Standard deviation of the zero-mean Gaussian prior on weights. Regularises the normal equations. Default 1000 (weak prior).

    		 1000.0
    norm_flux_err ndarray or None

    Per-pixel uncertainties on norm_flux used as observation weights. Must have the same shape as norm_flux.

    		 None
    coords str

    Coordinate system: "polar" (default) or "cartesian".

    		 'polar'
    n_col_knots int or None

    Cartesian: number of column-axis knots. Defaults to n_r_knots.

    		 None
    n_row_knots int or None

    Cartesian: number of row-axis knots. Defaults to n_r_knots.

    		 None
    log_fit bool

    When False (default), fits directly in linear flux space. This preserves the arithmetic mean of the flux distribution and avoids Jensen's inequality underestimation in the core. When True, fit log₁₀(norm_flux). Pixels with norm_flux ≤ 0 are excluded automatically. :meth:~PSFMachineModel.evaluate transforms back to linear flux via 10 ** (A @ weights).

    		 False
    cutout_size int or None

    Stamp size in native detector pixels. When provided (or inferred from 2D delta_col input), saved in the model and used to auto-calculate rmax to cover the entire square grid including corners.

    		 None

    Returns:

    Type Description
    PSFMachineModel

    Fitted model. :attr:~PSFMachineModel.coords and :attr:~PSFMachineModel.log_fit record the fitting configuration so that :meth:~PSFMachineModel.evaluate and :func:evaluate_epsf automatically apply the correct transforms.

    refine_centroids 

    refine_centroids(
    model: PSFMachineModel,
    selected_stars: DataFrame,
    image: ndarray,
    dq: ndarray | None,
    cutout_size: int,
    flux_col: str | None = None,
    background: str | None = "local",
    sigma_clip_bg: float = 3.0,
    norm_mode: str = "catalog",
    core_radius: float = 3.0,
    max_shift: float = 2.0,
) -> tuple[DataFrame, ndarray, ndarray, ndarray, ndarray]

    Update star centroid estimates by comparing each stamp to the current model.

    For each star the model is evaluated on the stamp grid and the flux-weighted centroid of the residual is used to compute a shift. The x_pix/y_pix columns in selected_stars are updated in-place and the pixel arrays are rebuilt with the new centres so the result can be fed directly into the next :func:fit_epsf call.

    Parameters:

    Name Type Description Default
    model PSFMachineModel

    Current best-fit ePSF model (e.g. from the previous iteration).

    		 required
    selected_stars DataFrame

    Star catalog with x_pix/y_pix columns.

    		 required
    image ndarray

    2D science image.

    		 required
    dq ndarray or None

    Data-quality array passed through to :func:build_pixel_arrays.

    		 required
    cutout_size int

    Stamp size in native pixels.

    		 required
    flux_col str or None

    Flux column name (forwarded to :func:build_pixel_arrays).

    		 None
    background str or None

    Background mode (forwarded to :func:build_pixel_arrays).

    		 'local'
    sigma_clip_bg float

    Sigma for background clipping (forwarded to :func:build_pixel_arrays).

    		 3.0
    norm_mode str

    Normalisation mode (forwarded to :func:build_pixel_arrays).

    		 'catalog'
    core_radius float

    Aperture radius in native pixels within which data pixels are used to compute the centroid shift. Default 3.0. Restricting centroiding to the high-SNR core prevents faint outer wing noise and asymmetries from exerting lever-arm torque and smearing the ensemble core peak.

    		 3.0
    max_shift float

    Maximum allowed centroid correction in native pixels. Larger shifts are clipped to avoid runaway corrections for blended/bad stars. Default 2.0.

    		 2.0

    Returns:

    Name Type Description
    updated_stars DataFrame

    Copy of selected_stars with updated x_pix/y_pix.
    delta_col, delta_row, norm_flux, star_idx : np.ndarray

    Pixel arrays rebuilt with the refined centres, ready for :func:fit_epsf.

    io

    roman_epsf.psfmachine.io

    FITS serialisation for :class:~roman_epsf.psfmachine.builder.PSFMachineModel.

    FITS layout

    save_model writes a two-extension FITS file:

    • PrimaryHDU — zero-size data; header holds all scalar parameters (RMIN, RMAX, CUT_R, NRKNOTS, NPHIKNOTS, DEGREE, NSTARS, NPIXELS) plus any caller-supplied extra keywords.
    • ImageHDU WEIGHTS — 1D float64 array of fitted spline coefficients.
    • ImageHDU R_KNOTS — 1D float64 array of radial knot positions.

    save_image evaluates the model on an oversampled grid and writes a plain 2D ImageHDU with oversampling metadata in the header.
